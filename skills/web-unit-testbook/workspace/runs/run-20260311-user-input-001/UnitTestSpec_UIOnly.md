①メールアドレス確認がメールアドレスと一致しない場合、チェックエラーが発生する。
②入力した「メールアドレス」のメールアドレスのフォマードをチェックします、メールアドレスの形式が正しくない場合「ご担当者のメールアドレスを正しいフォーマットで入力してください」というエラーメッセージが表示されます。

正規表現を使用してメールアドレスの形式をチェックします：

•　^ - 文字列の開始
•　[A-Za-z0-9]{1} - 最初の文字は英数字のみ
•　[A-Za-z0-9_.\-+]* - その後は英数字、アンダースコア、ドット、ハイフン、プラス記号が可能
•　@{1} - @マークが必須
•　[A-Za-z0-9_.-]+ - @の後には英数字、アンダースコア、ドット、ハイフンが1文字以上必要
•　\. - ドットが必須
•　[A-Za-z0-9]+ - ドメイン部分は英数字が1文字以上必要
•　$ - 文字列の終わり

例えば：

valid@example.com （有効）
user.name+tag@domain.com （有効）
@invalid.com （@マークの前に文字がないため無効）
invalid@ （ドットがないため無効）|画面表示・操作結果が仕様どおりであること|
